# Contributing to Trading Bot Console

Contributions to UI clarity, accessibility, mock-data behavior, tests, and
documentation are welcome.

## Setup

```bash
npm ci
npm run dev
```

Run the focused check for affected sorting behavior:

```bash
npm run test:sort
```

Keep pull requests focused, document visible behavior changes, and do not add
exchange credentials, account data, generated bundles, logs, local `.env`
files, or production configuration.
